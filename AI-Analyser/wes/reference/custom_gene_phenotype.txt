# Lab-curated gene-phenotype links missing from the HPO genes_to_phenotype.txt release.
#
# Loaded on top of genes_to_phenotype.txt; it only ever ADDS links, so a gene's phenotype
# score can rise but never fall because of this file. That makes every line a way to push
# a variant towards POSITIVE, so each one needs:
#   - a comment line above it naming the paper(s) - author, journal, year, PMID
#   - a scientist's sign-off (put their initials and the date in the comment)
#   - a check that the HPO ID exists in hp.obo (unknown IDs are silently ignored)
#
# Columns are tab-separated, same as genes_to_phenotype.txt:
# ncbi_gene_id	gene_symbol	hpo_id	hpo_name	frequency	disease_id
#
# Example (commented out - not a real addition):
# # PMID 00000000, Author et al., Journal 2020. Approved: AB 2026-11-16
# # 0000	GENE	HP:0000000	Term name	-	OMIM:000000
ncbi_gene_id	gene_symbol	hpo_id	hpo_name	frequency	disease_id
